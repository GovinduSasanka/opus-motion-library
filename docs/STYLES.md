# Styles

A **style** restyles any motion (or a whole mix) through one SVG filter chain + HTML overlays + optional "on twos"
re-timing — no per-motion code. 147 styles ship in `src/styles/defs/*.ts` (engine: `src/styles/engine.tsx`).

Use one:

```bash
node cli/mgl.mjs still ken-burns --style ukiyoe --out out/ukiyoe.png
node cli/mgl.mjs render box-bot --style cel-boil
```

```tsx
<StyleFrame style={styles['risograph']}>…</StyleFrame>     // Remotion
<MotionPlayer motion="city-skyline" look="paper-lantern" />  // web players, <opus-motion look="…">
```

Pick deliberately: every style lists `confusableWith`, `avoid` and `motionRules` in `styles.json`. Styles marked
*cutout* keep the motion's transparency, so overlay motions (captions, stickers, mascots) get die-cut borders.
To add a style, copy a def, keep steps few, and check a contact sheet (two contrasting motions) before shipping.

## Filter steps (engine)

tone/colour: `saturate` `contrast` `brightness` `posterize` `gradientMap`/`duotone` `threshold` `grade` `curve` `invert`
`autoInvert` `hue` `matrix` `tonemap` `clarity` `chromaKeep` `accentIsolate` `accentKeep`/`accentRestore` `palette` `dither` ·
print: `halftone` `lines` `plates` `cmyk` `misregister` `hatch` `celRegister` `stickerBorder` `specks` `tiles` ·
paint/material: `edges` `toon` `wobble` `bleed` `edgeDarken` `crackle` `relief` `tooth` `texture` `grain` `tint` ·
optics/screen: `pixelate` `blur` `glow` `bloom` (`streak`) `chroma` `tiltShift` `tape` `weave` `ascii`.

Overlays: `paper` (fiber / laid / rice / cold-press / mottle / canvas / kraft), `vignette`, `scanlines`, `letterbox`,
`deckle` (`freq` for a frayed paint edge), `frameLine`, `filmGrain`, `leak`, `crt`, `vhs`, `filmDamage`, `gate`, `mat`,
`grid`, `sheen`, `light` (spot / band / blinds / window / mist / foot), `osd` (REC / PLAY counter).
