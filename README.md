# Opus Motion Library

A reusable, parameterised **motion-graphics library** reverse-engineered from 23 videos generated by Claude Opus 5.5.
Every motion in those films was taken apart frame by frame, measured (timing, easing, colours, layout), documented,
and rebuilt as a [Remotion](https://www.remotion.dev/) component you can call by name with your own text, colours,
images and timing. It ships with a CLI that renders single motions, stills and contact sheets, a **composer** that
stitches motions into one video with transitions, overlays, music and sound effects, and a **director** that turns a
JSON storyboard into a narrated, captioned, loudness-mastered MP4 using only local models.

![Every motion in the library](docs/library-overview.jpg)

- **106 motions** in 11 families: text, shapes, fx, environments, characters, data, UI, HUD, images, 3D (+ a transition reel).
- **33 scene transitions** (iris, ink blob, torn paper, page turn, whiteout, glitch, ripple, spiral, liquid wave…).
- **Resolution independent**: every motion renders at 16:9, 1:1 and 9:16.
- **Deterministic**: seeded randomness; the same props always give the same frames.
- **Narrated videos from a storyboard**: local Qwen3-TTS voice, Whisper speech check, captions, ducked music, loudness mastering. No cloud services.

The demo film ([download demo.mp4 (8 min, 1080p) from the v1.0.0 release](https://github.com/GovinduSasanka/opus-motion-library/releases/tag/v1.0.0))
walks through every motion as one connected story: a single dot that learns to move, makes things, flies as a paper
crane, dives into the deep, meets characters, becomes pictures, data and words, and ends with a full mix of everything.

## Transitions

`src/transitions.tsx` implements 33 transition presentations for `@remotion/transitions`. A scene in a compose spec or
storyboard carries `"transition": {"type": "...", ...}`, which plays **into** the next scene. Recommended lengths in
frames live in [`transitions.json`](transitions.json) (written by `gen-registry`):

| type (variants) | frames | type (variants) | frames |
|---|---|---|---|
| `cut` | 0 | `ripple` | 12 |
| `fade` / `slide` / `wipe` | 15 | `spiral` | 18 |
| `clock` / `flip` | 20 | `wave` (`lines`) | 14 (36) |
| `iris` | 8 | `bands` (`center`) | 10 (12) |
| `blob` | 18 | `diagonal` | 10 |
| `tear` | 12 | `push-blur` | 12 |
| `zoom` | 14 | `page-turn` (`roll`) | 22 (60) |
| `flash` (`plain`) | 20 (12) | `storm` (`watercolor`) | 20 (34) |
| `glitch` | 15 | `whiteout` (`burnout`, `blizzard`) | 42 (24, 36) |
| `xray` | 10 | `bar` (`black`) | 8 (10) |
| `strip` | 24 | `dots` (`bokeh`) | 16 (20) |

Common fields: `frames`, `direction` (`from-left|right|top|bottom`), `angle`, `x`/`y` origin, `color`, plus
per-type options (`variant`, `seed`, `size`, `bands`, …). If `frames` is omitted, the composer uses 15. Full reference:
[`docs/TRANSITIONS.md`](docs/TRANSITIONS.md). Preview them all with `node cli/mgl.mjs render transition-reel`.

## How it works

```
 src/motions/<family>/<id>.tsx  -- defineMotion({id, title, category, props, propDocs, component, ...})
              |
   node cli/gen-registry.mjs  -->  src/registry.ts   (imports every motion)
              |                    catalog.json       (metadata + prop docs, for the CLI)
              |                    transitions.json   (recommended transition lengths)
   node cli/gen-docs.mjs      -->  docs/CATALOG.md, docs/TECHNIQUES.md
              |
   src/index.ts -> src/Root.tsx     Remotion compositions:
              |     "Motion"   one motion by id with user props (size/fps/frames from inputProps)
              |     "Compose"  a ComposeSpec (src/Compose.tsx)
              |     landscape-/square-/portrait-<id>   every motion in 3 aspect ratios (for Studio)
              |
   cli/mgl.mjs  --> @remotion/bundler + @remotion/renderer (headless Chrome, ANGLE GL) --> out/*.mp4 | *.png
              |
   cli/direct.mjs  (storyboard.json)
        1. narration  cli/voice.py (Qwen3-TTS, local) --> public/voice/<name>/sNNN.wav
                      cli/voice-check.py (Whisper) flags lines that differ from the script
        2. timing     scene length = max(min, lead + speech + pad); caption cues in short chunks;
                      music-ducking cues; writes a compose spec
        3. render     "Compose" composition --> temporary mp4
        4. master     ffmpeg loudnorm (I=-16, TP=-1.5, LRA=11), 48 kHz AAC 192k --> out/<name>.mp4
```

**Core kits** (`src/core/`):

| file | role |
|---|---|
| `ease.ts` | measured easing curves and helpers (`ease.*`, `prog`, `tween`, `springAt`, `envelope`) |
| `random.ts` | seeded RNG, `scatter`, 2D/3D noise and fbm (no `Math.random`) |
| `stage.tsx` | `useStage()` (`w, h, u, cx, cy, portrait`), Svg, Camera, handheld, paper texture, film grain, vignette, scanlines |
| `shapes.tsx` | glossy sphere, sparkle, smooth paths, regular polygons, draw-on |
| `fonts.ts` | font roles (sans, display, mono, serif, comic, hand, grotesk) via `@remotion/google-fonts` |
| `*-kit.tsx` | shared building blocks per family: text, shape, fx, environment, character, image, hud, ui, three, world, sketch, void, principles |
| `types.ts` | `MotionDef` and `Category` types |

**Composer** (`src/Compose.tsx`): a `ComposeSpec` has `width`, `height`, `fps`, `background`, `scenes[]`
(`motion`, `duration`, `props`, `offset`, `transition`), `overlays[]` (`motion`, `from`, `duration`, `props`),
`captions` / `duckCues` / `captionStyle`, and `audio` (`voice`, `music`, `musicVolume`, `duck`, `musicStart`,
`musicCues[]`, `sfx[]`). Music automatically ducks while voice cues play.

## Tech stack

- **Remotion 4.0.532** (`remotion`, `@remotion/cli`, `bundler`, `renderer`, `transitions`, `three`, `noise`, `paths`, `layout-utils`, `google-fonts`)
- **React 19**, **TypeScript 5**, SVG for vector looks
- **three.js 0.169** + **@react-three/fiber** for the real-3D motions (`src/motions/3d/`)
- **FFmpeg** for mastering and contact sheets
- **Python** (optional): `qwen-tts` + PyTorch + `soundfile` for narration, `openai-whisper` for the speech check
- ES-module Node scripts in `cli/`; no build step beyond Remotion's bundler

## Requirements and setup

- Node.js 20+ and FFmpeg on `PATH`.
- Rendering uses headless Chrome (downloaded by Remotion on first render) with ANGLE for WebGL.
- Narration (optional): a Python environment with PyTorch, `qwen-tts` and `soundfile`, and an NVIDIA GPU with about 4 GB
  free (it falls back to CPU, slowly). Point `QWEN_PYTHON` at that environment's Python executable.
- Speech check (optional): a Python environment with `openai-whisper`.

```bash
git clone https://github.com/GovinduSasanka/opus-motion-library.git
cd opus-motion-library
npm install
node cli/gen-registry.mjs      # writes src/registry.ts, catalog.json, transitions.json
node cli/gen-docs.mjs          # optional: regenerates docs/CATALOG.md and docs/TECHNIQUES.md
npm run typecheck              # optional
```

| script | runs |

### `cli/mgl.mjs`

```bash
node cli/mgl.mjs list [--category text]            # every motion, one line each
node cli/mgl.mjs info depth-descent                # props, defaults, source

node cli/mgl.mjs still origami-fold --frame 60                                       # one PNG
node cli/mgl.mjs still origami-fold --at 20,80,140,200 --out out/origami-sheet.jpg   # contact sheet
node cli/mgl.mjs compose specs/my-video.json --out out/my-video.mp4                  # multi-scene video
node cli/mgl.mjs gallery [--only a,b] [--force]                                      # gallery/<id>.jpg strips
```

Options: `--format landscape|square|portrait` (1920x1080, 1080x1080, 1080x1920), `--size WxH`, `--frames`, `--fps`,
`--out`, `--concurrency` (default 8). Videos are H.264, CRF 18, yuv420p, AAC.

### Compose several motions into one video

```jsonc
// specs/my-video.json
{
  "width": 1920, "height": 1080, "fps": 30,
  "scenes": [
    {"motion": "blur-in-title", "props": {"title": "DEEP SEA", "swapTo": null}, "transition": {"type": "wave"}},
    {"motion": "depth-descent", "duration": 300, "transition": {"type": "flash", "variant": "plain"}},
    {"motion": "giant-eye-reveal"}
  ],
  "overlays": [{"motion": "film-look", "from": 0, "duration": 600, "props": {"overlay": true}}]
}
```
```bash
node cli/mgl.mjs compose specs/my-video.json --out out/my-video.mp4
```
See also `specs/demo.json`, `specs/test-transitions.json` and `specs/test-finale.json`.

### Make a narrated video from a storyboard

```jsonc
// storyboards/my-story.json
{
  "name": "my-story",
  "voice": {"speaker": "Ryan", "style": "warm documentary narrator"},
  "scenes": [
    {"motion": "sonar-ping", "say": "Every motion starts with a single dot.", "music": {"file": "music/inspiring.mp3"}, "transition": {"type": "iris"}},
    {"motion": "handwrite-on", "props": {"lines": [{"text": "hello"}]}, "say": "And a pen that writes its name."}
  ]
}
```
```bash
node cli/direct.mjs storyboards/my-story.json [--out out/my-story.mp4] [--no-render] [--no-voice]
```

Storyboard fields: `name`, `width`, `height`, `fps`, `voice` (`speaker`, `style`, `seed`, `model`), `music`
(`file`, `volume`, `start`, `duck`), `captions`, `captionStyle`, and per scene: `motion`, `props`, `say`,
`direction` (delivery note), `min`, `lead`, `pad`, `caption`, `transition`, `overlays[]`, `sfx[]`, `music`.
Each scene lasts `max(min, lead + speech + pad)` frames. Voice lines are cached in `public/voice/<name>/` and are only
regenerated when their text changes. See `storyboards/demo.json` for the full 8-minute example.

### Use from Claude Code

`.claude/skills/opus-motion/SKILL.md` is a Claude Code skill that teaches an agent to find motions (`list` / `info`),
render them, compose them and direct narrated videos with this library.

### Adding a motion

Follow [`docs/AUTHORING.md`](docs/AUTHORING.md): one file exporting `defineMotion({...})`; deterministic
(`rng`/noise from `src/core/random.ts`); sized in `u` units from `useStage()`; JSON-only props, each with a default and
a `propDocs` line; SVG first (three.js only for real 3D). Then run `node cli/gen-registry.mjs`.

## How it was built

1. **Analysis**: each of the 23 sample videos was cut into contact sheets (`analysis/sheets/`), then measured with
   frame bursts and pixel sampling. `analysis/videoN.md` documents every technique: what it looks like, measured
   durations and easing curves, hex palettes, typography, and an implementation recipe. **320 techniques** in total.
2. **Consolidation**: `docs/PLAN.md` merges those 320 techniques into 106 generalised motions whose props reproduce
   every source variant. `docs/TECHNIQUES.md` maps each source technique to the motion that rebuilds it.
3. **Implementation**: each motion is one file in `src/motions/<family>/` following `docs/AUTHORING.md`, verified
   with stills in landscape and portrait and compared against the source frames.

## Notes and limitations

- Output goes to `out/` (git-ignored). The default frame rate is 30 fps.
- 3D motions need WebGL; renders use Chrome with `gl: angle`.
- Narration needs a local Python environment with `qwen-tts` (a GPU is strongly recommended); use `--no-voice` to skip it.
- The Claude Code skill and the `QWEN_PYTHON` default reference paths on the author's Windows machine.
- The 23 sample videos are not included in the repository. The rendered demo is attached to the v1.0.0 release, not committed.
