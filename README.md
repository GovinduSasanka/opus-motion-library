# Opus Motion Library

A reusable, parameterised **motion-graphics library** reverse-engineered from 23 videos generated by Claude Opus 5.5.
Every motion in those films was taken apart frame by frame, measured (timing, easing, colours, layout), documented,
and rebuilt as a Remotion component you can call by name with your own text, colours, images and timing.

![Every motion in the library](docs/library-overview.jpg)

- **109 motions** in 12 families: text, shapes, fx, environments, characters, data, UI, HUD, images, 3D, mix (+ a transition reel).
- **19 recipes** — ready, previewed mixes (hero backgrounds, launch intro, stats, testimonial, loader, social short…).
- **Use it anywhere** — render video, play live in React / Next.js / plain HTML (`MotionPlayer`, `MotionBackground`, `<opus-motion>`), or export mp4 / webm-alpha / ProRes 4444 / GIF for apps and editors. AI agents: start at [AGENTS.md](AGENTS.md).
- **33 scene transitions** (iris, ink blob, torn paper, page turn, whiteout, glitch, ripple, spiral, liquid wave…).
- **Resolution independent** — every motion renders at 16:9, 1:1 and 9:16.
- **Deterministic** — seeded randomness; the same props always give the same frames.
- **Narrated videos from a storyboard** — local Qwen3-TTS voice, captions, ducked music, loudness mastering. No cloud services.

**Demo film** — **[watch / download (8 min, 1080p)](https://github.com/GovinduSasanka/opus-motion-library/releases/tag/v1.1.0)**:
a premium showreel of every motion. A cinematic cold open, then eleven chapters (Motion, Form, Worlds, The Deep,
Characters, Images, Data & Interfaces, Systems, Dimension, Type, Mix), each motion labelled with its index, captions
that light up word by word with the narration and sit in the calmest part of each frame, cuts on the music's beats,
and a full-mix finale. Rebuild it with `python storyboards/build-demo.py && node cli/direct.mjs storyboards/demo.json`.

## Quick start

```bash
npm install
node cli/gen-registry.mjs                  # registry + catalog.json (+ transitions.json)
node cli/mgl.mjs list                      # every motion, one line each
node cli/mgl.mjs info depth-descent        # props, defaults, source
node cli/mgl.mjs render sonar-ping         # -> out/sonar-ping.mp4
node cli/mgl.mjs render stamp-slam --props '{"lines":["HELLO","2026"],"keyword":"WORLD"}' --format portrait
node cli/mgl.mjs still origami-fold --at 20,80,140,200 --out out/origami-sheet.jpg
npm run studio                             # browse every motion in Remotion Studio
```

### Compose several motions into one video

```jsonc
// specs/my-video.json
{
  "width": 1920, "height": 1080, "fps": 30,
  "scenes": [
    {"motion": "blur-in-title", "props": {"title": "DEEP SEA", "swapTo": null}, "transition": {"type": "wave"}},
    {"motion": "depth-descent", "duration": 300, "transition": {"type": "flash", "variant": "plain"}},
    {"motion": "giant-eye-reveal"}
  ],
  "overlays": [{"motion": "film-look", "from": 0, "duration": 600, "props": {"overlay": true}}]
}
```
```bash
node cli/mgl.mjs compose specs/my-video.json --out out/my-video.mp4
```

### Make a narrated video from a storyboard

```jsonc
// storyboards/my-story.json
{
  "name": "my-story",
  "voice": {"speaker": "Ryan", "style": "warm documentary narrator"},
  "scenes": [
    {"motion": "sonar-ping", "say": "Every motion starts with a single dot.", "music": {"file": "music/inspiring.mp3"}, "transition": {"type": "iris"}},
    {"motion": "handwrite-on", "props": {"lines": [{"text": "hello"}]}, "say": "And a pen that writes its name."}
  ]
}
```
```bash
node cli/direct.mjs storyboards/my-story.json            # voice -> timing -> captions -> render -> master
```
Each scene lasts `max(min, lead + speech + pad)` frames, nudged so cuts land on the music's beats (`"music": {"snap": true}`,
beat grids from `cli/beats.py`). Narration is generated locally with Qwen3-TTS (`cli/voice.py`); Whisper
(`cli/voice-check.py`) checks it and aligns every word, so `"captionStyle": {"variant": "premium"}` captions light up word
by word in sync. Caption placement and the optional index tags (`"tag": true`) are chosen per scene from rendered stills
(`cli/zones.py`): captions take the calmer band and a contrasting tone so they never sit on a motion's own text.
Scenes can also be `"layers"` (a mix of several motions).
See `storyboards/demo.json` for a full 8-minute example.

## Use it in your project

Copied or linked into another project? Start with **[AGENTS.md](AGENTS.md)** (written for the AI agent doing the work),
[docs/CHOOSING.md](docs/CHOOSING.md) (goal → motions, recipes, pairings) and [docs/INTEGRATION.md](docs/INTEGRATION.md) (per stack).

```bash
node cli/mgl.mjs suggest "dark hero for an AI tool with a stats section"   # ranked recipes + motions, why, props
node cli/mgl.mjs recipes                                                  # 19 ready-made mixes (recipes/previews/)
node cli/mgl.mjs recipe hero-aurora-night --overrides '{"blur-in-title":{"title":"ACME"}}'
node cli/mgl.mjs add product-launch number-counter --to ../my-video/src   # copy just that source into a Remotion / React project
node cli/mgl.mjs export confetti-burst --as webm-alpha                     # mp4 | webm-alpha | prores-alpha | gif | png | poster
npm run build:lib                                                         # dist/: ESM (+ code-split /web), <opus-motion> element, types
```
```tsx
import {MotionBackground, MotionPlayer} from 'opus-motion-library/web';   // React / Next.js ('use client') / Vite
<MotionBackground recipe="hero-aurora-night" style={{minHeight: '90vh'}}><h1>Your headline</h1></MotionBackground>
```
```html
<script src="opus-motion.element.js" defer></script>                      <!-- plain HTML, WordPress, Vue, Svelte -->
<opus-motion recipe="hero-aurora-night" background></opus-motion>
```
Working, screenshot-verified examples: `examples/react-vite/`, `examples/html/`, `examples/remotion-project/`.

## How it was built

1. **Analysis** — each of the 23 sample videos was cut into contact sheets (`analysis/sheets/`), then measured with
   frame bursts and pixel sampling. `analysis/videoN.md` documents every technique: what it looks like, measured
   durations and easing curves, hex palettes, typography, and an implementation recipe. **320 techniques** in total.
2. **Consolidation** — `docs/PLAN.md` merges those 320 techniques into 106 generalised motions whose props reproduce
   every source variant. `docs/TECHNIQUES.md` maps each source technique to the motion that rebuilds it.
3. **Implementation** — each motion is one file in `src/motions/<family>/` following `docs/AUTHORING.md`, verified
   with stills in landscape and portrait and compared against the source frames.

## Layout

```
src/core/          easing (measured curves), seeded noise, stage (u-units, camera, paper, grain), shapes, fonts, family kits
src/motions/       one file per motion, grouped by family
src/transitions.tsx   33 transition presentations (docs/TRANSITIONS.md)
src/Compose.tsx    multi-scene composer: scenes, transitions, overlays, captions, music cues, sfx
cli/mgl.mjs        list | info | render | still | compose | gallery | suggest | recipes | recipe | add | export
src/web/           MotionPlayer / MotionMix / MotionBackground (Remotion Player) and the <opus-motion> element
recipes/           ready-made mixes (layer stacks / multi-scene specs) + previews
examples/          react-vite, html, remotion-project (integration examples)
cli/direct.mjs     storyboard -> narrated, captioned, mastered video
cli/voice.py       local Qwen3-TTS narration;  cli/voice-check.py  Whisper speech check
analysis/          contact sheets + reverse-engineering notes for each sample video
docs/              PLAN, AUTHORING, CATALOG (every motion + props), TECHNIQUES, TRANSITIONS
storyboards/       narrated demo storyboard;  specs/  compose specs
public/            demo plates (Codex-generated), music + sfx (Pixabay licence, see *.json), voice cache
gallery/           preview frame of every motion
```

## Requirements

- Node.js 20+, FFmpeg on PATH. Rendering uses headless Chrome (downloaded by Remotion) with ANGLE for WebGL.
- Narration (optional): a Python env with PyTorch + `qwen-tts` (point `QWEN_PYTHON` at it; `librosa` in the same env gives beat-snapped cuts),
  an NVIDIA GPU with ~4 GB free. Speech check: a Python env with `openai-whisper`.
